# game-tetris

순수 HTML/CSS/JavaScript로 만든 브라우저 테트리스 게임입니다.

## 프로젝트 설명

- 10x20 보드 기반의 기본 테트리스 규칙을 구현했습니다.
- 7종 블록, 점수/레벨/콤보 시스템, Next/Hold 미리보기를 포함합니다.
- Web Audio API로 효과음/배경음악을 코드에서 생성합니다.

## 실행 방법

1. `game-tetris` 폴더로 이동합니다.
2. `index.html` 파일을 브라우저에서 엽니다.
3. `시작` 버튼을 눌러 게임을 시작합니다.

## 조작 방법

- `←` : 왼쪽 이동
- `→` : 오른쪽 이동
- `↓` : 빠른 하강
- `↑` : 회전
- `Space` : 즉시 떨어뜨리기
- `C` 또는 `Shift` : 현재 블록 보관 / Hold 블록과 교체
- `P` : 일시정지 / 재개
- `R` : 재시작

## 주요 기능

- 10x20 보드, 7종 블록(I/O/T/S/Z/J/L)
- 자동 낙하, 좌우 이동, 회전, 소프트 드롭, 하드 드롭
- 블록 고정, 줄 제거, 게임 오버
- 시작/일시정지/재시작
- Next 블록 미리보기
- Hold 기능
- Hold 블록 미리보기
- 점수/줄 수/레벨/플레이 시간 표시
- 라인 클리어 및 콤보 팝업 연출
- Web Audio API 기반 효과음/배경음악
- 효과음 ON/OFF, 배경음악 ON/OFF, 전체 음량 슬라이더
- 사운드 설정 localStorage 저장

## 학습 목적

- 캔버스 기반 게임 루프 이해
- 충돌 판정/줄 제거/회전 등 게임 로직 구현
- 키 입력 처리와 상태 관리 연습
- Web Audio API 기초 활용
- localStorage로 사용자 설정 유지
